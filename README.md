# 🤖 게이미피케이션 기반 지능형 자원 순환 수거 로봇 (EcoCat)

> **AI 객체 인식과 자동화 로봇 공학을 결합한 지능형 하이브리드 수거 로봇 플랫폼**
> 

## 📌 프로젝트 소개

기존 분리배출 정책은 시민의 양심과 사후 처리(선별장)에 의존하여 실질적인 물질 재활용률(플라스틱 기준 16.4%)이 저조한 한계가 있습니다.
본 프로젝트는 폐기물을 배출하는 순간(Point of Disposal)에 원천적으로 재질과 오염도를 실시간 판별하고 분류하는 지능형 게이트키핑 시스템입니다.
여기에 즉각적인 포인트 보상을 제공하는 게이미피케이션을 결합하여, 억지로 하는 분리배출을 자발적이고 수익이 되는 참여로 혁신하고자 합니다.

**프로젝트 목표**

* 폐기물 배출 단계에서 AI가 오염도와 재질을 사전 판별하는 지능형 시스템 구축


* 사용자 참여를 유도하는 즉각적인 에코 포인트 리워드 시스템 연동


* 오염·혼입된 쓰레기를 원천 차단하여 재활용 원료의 순도를 높이고 잔재 폐기물 저감


* 수거량을 탄소 절감량으로 환산하여 ESG 모니터링 근거 데이터 제공



## 🖥️ 주요 기능

### 1. 🧠 초고속 AI 객체 및 오염도 인식

* Raspberry Pi 5와 Hailo-8 NPU 가속 환경에서 YOLOv8s 모델을 구동하여 폐기물을 실시간 인식합니다.


* 투입부터 판별까지 100ms 이내로 5종 재질과 오염 여부(총 10가지 클래스)를 식별합니다.


* 5프레임 다수결 스무딩(Majority Voting) 알고리즘을 적용하여 프레임 깜빡임이나 순간적인 오탐지를 자체 보정합니다.



### 2. ⚙️ 지능형 기구부 물리 선별 제어

* 무거운 통 전체를 회전시키는 대신, 가벼운 미끄럼틀(다단 슬라이딩 플랩)만 회전시키는 고속 경량 구동 방식을 적용했습니다.


* ROS2 노드와 Arduino Mega 간 비동기 시리얼 통신을 통해 스텝 모터의 최단 거리 회전 경로를 연산하여 조준합니다.


* 초음파 센서를 활용해 5분할 수거함의 물리적 적재량(%)을 실시간으로 감지합니다.



### 3. 🎮 게이미피케이션 및 다이내믹 세션 연동

* 로봇 전면의 7인치 터치 디스플레이를 통해 무작위 6자리 PIN 번호를 표출하여 사용자의 스마트폰 앱과 연동합니다.


* 투입된 쓰레기가 오염되지 않은 세척된 상태(Clean)일 경우, 모바일 앱을 통해 10 EXP(경험치)를 즉시 보상으로 지급합니다.


* SQLite3 기반의 유저 랭킹 시스템을 통해 다중 조건 정렬(레벨, 경험치 등) 기반의 경쟁을 유도합니다.



### 4. 📈 원격 모니터링 및 ESG 대시보드

* 수집된 적재량 및 재활용 데이터를 바탕으로 기기 상태와 누적 수거량을 모니터링합니다.


* 수거 데이터를 탄소 절감량(CO2e) 지표로 환산하여 관리자용 웹 플랫폼에 시각화합니다.


* Flask 웹 프레임워크와 Socket.IO 프로토콜을 사용해 수거함 포화도 데이터를 웹 대시보드로 실시간 브로드캐스팅합니다.



## 🧠 시스템 아키텍처

본 프로젝트는 엣지 AI, 분산 로봇 미들웨어, 그리고 클라우드 데이터베이스를 유기적으로 결합한 3-Tier 아키텍처를 가집니다.

* **AI 추론 파이프라인**: 백그라운드 스레드 기반의 비동기 I/O를 적용하여 메인 NPU 추론과 카메라 프레임 수신 병목을 분리했습니다.


* **ROS 2 미들웨어 기반 통신**: 영상 처리 노드와 모터 제어 노드를 DDS 기반의 비동기 Pub/Sub 모델로 격리하여 시스템 다운을 방지합니다.


* **웹 소켓 브릿지**: ROS 2의 메시지 루프와 웹 서버 루프 간의 교착 상태(Deadlock)를 방지하기 위해 멀티스레딩 기반 이벤트 루프 격리 기법을 사용했습니다.



## 🛠️ 기술 스택

* **Language**: Python, C/C++(Arduino)


* **Edge AI / Vision**: YOLOv8s, OpenCV, Hailo Dataflow Compiler


* **Hardware**: Raspberry Pi 5, Hailo-8 AI 가속기, Arduino Mega 2560 (R3), 스텝/서보 모터, HC-SR04P 초음파 센서


* **Middleware / OS**: ROS 2 Jazzy, Ubuntu(Docker 컨테이너), Raspberry Pi OS


* **Backend / Database**: FastAPI, Flask, Socket.IO, SQLite3, AWS EC2


* **3D Design**: Autodesk Fusion

## 🚀 실행 방법

**1. ROS 2 및 하드웨어 통신 노드 실행**

```bash
# ROS2 워크스페이스 빌드 및 환경 설정
colcon build
source install/setup.bash

# 스텝 모터 및 센서 제어용 시리얼 통신 노드 실행
ros2 run sorting_motor_node sorting_motor

```

**2. 백엔드 API 및 웹 소켓 대시보드 서버 가동**

```bash
# 사용자 세션 및 포인트 관리 FastAPI 서버 실행
uvicorn backend.main:app --host 0.0.0.0 --port 8000

# 대시보드 실시간 연동용 Flask Socket.IO 브릿지 서버 실행
python3 ui_bridge_node.py

```

**3. Edge AI 추론 파이프라인 실행**

```bash
# Hailo-8 NPU 가속 기반의 실시간 카메라 추론 시스템 구동
python3 inference/hailo_infer.py --hef model/hard_800.hef

```

## 📊 서비스 및 하드웨어 화면 구성

* **AI 객체 인식 화면**: 카메라를 통해 투입된 쓰레기의 Bounding Box(재질 및 Clean/Dirty 상태)와 신뢰도 점수를 실시간으로 표출합니다.


* **로봇 하드웨어 기구부**: 자체 3D 프린팅된 깔때기와 미끄럼틀을 통해 낙하를 일시 차단하고, 스텝모터 회전 후 해당 칸으로 쓰레기를 자유낙하 시킵니다.


* **모바일 뷰 & 대시보드**: 사용자 앱에서 실시간 경험치(EXP)와 탄소 절감 효과를 모니터링할 수 있으며, 관리자는 수거함의 적재율(0~100%)을 웹에서 확인할 수 있습니다.



## 💡 기대 효과

* 분리배출 시 오염 없는 깨끗한 분류를 통해 폐기물 판매 수익을 최대 45% 증대시킵니다.


* 인공지능 기반의 선별 자동화를 구현하여 수거 운영 비용을 약 30% 절감할 수 있습니다.


* 오염된 쓰레기 선별 작업을 로봇이 대신 수행함으로써 환경미화 노동자의 고강도 노동 부담을 경감시킵니다.


* 투입량을 탄소 절감량 지표로 환산하여 대학이나 기업의 객관적인 ESG 성과 근거 자료로 활용할 수 있습니다.
